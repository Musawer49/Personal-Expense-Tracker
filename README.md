#  Personal Expense Tracker

A desktop app for tracking personal spending, built with Python and Tkinter. No extra libraries needed.

<img width="1917" height="1020" alt="screenshot png" src="https://github.com/user-attachments/assets/6e4d994e-d45f-4053-ac13-865d14ae7258" />


## Features
- Add, edit and delete expenses, with undo for the last deletion
- Live search, category filter and sortable columns
- Color-coded categories
- Stats cards: total, number of transactions, highest and average expense
- Monthly summary with a budget progress bar and a warning near the limit
- Category Analysis (pie chart and bars) and a Monthly Chart
- Export to CSV
- Keyboard-friendly: press Enter to add, "Today" button for the date

## How to run
1. Install Python 3 (Tkinter comes with it)
2. Download or clone this repository
3. Run:
```
python Personal_Expense_Tracker.py
```

## Built with
Python and Tkinter, developed one small step at a time.
